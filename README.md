# Quiet Finance Homebrew tap

Homebrew tap for [Quiet Finance](https://github.com/quietapps/QuietFinance) — a native macOS app for tracking net worth via dated account snapshots. SwiftUI + SwiftData, 100% local.

## Install

```sh
brew tap quietapps/quietfinance
brew install --cask quietfinance
```

## Update

```sh
brew update
brew upgrade --cask quietfinance
```

## Uninstall

```sh
brew uninstall --cask quietfinance
brew untap quietapps/quietfinance
```
